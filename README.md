## 🛠️ Key Features
* **Java Edition on Mobile:** Run full releases, snapshots, and older alpha/beta builds smoothly.
* **In-App Downloads:** Easily download mods, shader packs, and resource packs directly inside the interface.
* **Account Integration:** Supports both official Microsoft account login and offline profile configurations.
* **Performance Enhancements:** Optimized rendering pipelines (Vulkan/Zinc) tailored for Android hardware.
