# Security Policy

## Supported Versions
Only the official builds downloaded from verified channels managed by **Saif Khan** are supported.

## Reporting a Vulnerability
If you find any security flaws, bugs, or malicious clones of Zyron Launcher, please do not report them publicly. Instead, contact the developer directly through the official Discord server or community channels.

*Protected by Saif Khan (@ZyronLauncher)*
